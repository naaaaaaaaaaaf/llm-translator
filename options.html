LLM Translator 設定

LLM Translator について

LLM Translatorは、高性能AI言語モデル（LLM）を活用した翻訳拡張機能です。選択したテキストをAIモデルを使用して翻訳し、自然で高品質な翻訳結果を提供します。

使用方法: テキストを選択し、右クリックメニューから「選択テキストを翻訳」を選択するだけです。翻訳結果は新しいタブで表示され、自動的に翻訳履歴に保存されます。

このページでは、使用するAIサービス、モデル、APIキーなどの設定を行えます。

使用したいAIサービスを選択してください。各サービスごとにAPIキーが必要です。

選択したサービスとモデルが翻訳に使用されます。サービスごとの特徴:

  • OpenAI ChatGPT: 高品質な翻訳が可能ですが、APIキーの取得と使用には料金がかかります。
  • Anthropic Claude: 長文の翻訳に強みがあり、文脈を考慮した自然な翻訳を提供します。APIキーの取得と使用には料金がかかります。
  • Google Gemini: Gemini APIの無料枠を使用することで、無料で翻訳機能を利用できます。特にGemini 1.5 Flashモデルは無料枠の範囲内でも高品質な翻訳が可能です。

APIキー設定

OpenAI APIキーを入力してください。形式: sk-...

OpenAI APIキーの取得方法:

  1. OpenAIのプラットフォームでアカウント作成
  2. ダッシュボードから「API Keys」を選択
  3. 「Create new secret key」をクリックして新しいキーを作成
  4. 料金は使用量に応じて発生しますこちら
Anthropic Claude APIキーを入力してください。形式: sk-ant-...

Claude APIキーの取得方法:

  1. Anthropic Consoleにアクセスしてアカウント作成
  2. コンソールから「API Keys」セクションに移動
  3. 「Create API Key」をクリックして新しいキーを作成
  4. 料金は使用量に応じて発生します。詳しくはこちら
Google AI Studio APIキーを入力してください。

Gemini APIキーの取得方法:

  1. Google AI Studioにアクセスしてログイン
  2. 「Get API key」をクリック
  3. 新しいキーを作成するか既存のキーをコピー
  4. 無料枠: 使用するモデルによってレートリミットが異なります。詳しくはこちら
