# LLM Translator

LLM Translatorは、高性能AI言語モデル（LLM）を活用した翻訳Chromeブラウザ拡張機能です。ChatGPT、Claude、Geminiなどの最新AIモデルを使用して、選択したテキストを自然で高品質に翻訳します。

![LLM Translator Icon](images/icon128.png)

## 特徴

- **複数のAIサービス対応**: OpenAI ChatGPT、Anthropic Claude、Google Geminiなど、複数のAIプロバイダーを利用可能
- **モデル選択**: 各サービスで最新のAIモデルから選択可能（GPT-4o、Claude 3.7、Gemini 2.5など）
- **カスタムモデル追加**: 新しいモデルがリリースされた際に、管理画面から簡単に追加可能
- **翻訳履歴管理**: 過去の翻訳をすべて保存し、検索・フィルタリング可能
- **高度なフィルタリング**: 言語、AIサービス、モデルバージョンによる履歴のフィルタリング
- **簡単操作**: テキストを選択して右クリックするだけで翻訳を実行
- **コピー機能**: 翻訳結果をワンクリックでクリップボードにコピー

## 必要な権限とその理由

この拡張機能は以下の権限を必要とします：

- **storage**: APIキー、言語設定、モデル選択、翻訳履歴などのデータを保存するために必要です。この権限がないと設定や履歴が保存できません。
- **contextMenus**: 選択したテキストを右クリックして表示されるコンテキストメニューに「選択テキストを翻訳」メニューを追加するために必要です。この機能が拡張機能の主要な操作方法となります。
- **activeTab**: 現在表示中のタブから選択されたテキストにアクセスするために必要です。この権限がないとユーザーが選択したテキストを取得できません。
- **ホスト権限（\<all_urls\>）**: どのウェブサイトでも翻訳機能を使えるようにするために必要です。特定のサイトだけでなく、あらゆるサイトでテキスト選択と翻訳を行えるようにします。

これらの権限は拡張機能の核となる機能を実現するために必須であり、ユーザーのプライバシーを尊重する形で最小限に抑えられています。

## インストール方法

1. このリポジトリをダウンロードまたはクローンします
2. Chromeブラウザで `chrome://extensions/` を開きます
3. 右上の「デベロッパーモード」をオンにします
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、ダウンロードしたフォルダを選択します

## 初期設定

1. 拡張機能をインストール後、ブラウザ右上の拡張機能アイコンからLLM Translatorアイコンをクリックします
2. 「API設定」ボタンをクリックして設定画面を開きます
3. 使用したいAIサービス（ChatGPT、Claude、Gemini）を選択します
4. 選択したサービスのAPIキーを入力します
   - OpenAI: [OpenAIのプラットフォーム](https://platform.openai.com/)でAPIキーを取得
   - Claude: [Anthropic Console](https://console.anthropic.com/)でAPIキーを取得
   - Gemini: [Google AI Studio](https://aistudio.google.com/)でAPIキーを取得
5. デフォルトの翻訳先言語を選択します
6. 「保存」ボタンをクリックして設定を保存します

## 使用方法

### 基本的な翻訳

1. ウェブページ上で翻訳したいテキストを選択します
2. 選択したテキストを右クリックし、コンテキストメニューから「選択テキストを翻訳」を選択します
3. 翻訳結果が新しいタブで表示されます

### 翻訳履歴の確認

1. 拡張機能アイコンをクリックし、「翻訳履歴を表示」ボタンをクリックします
2. または、任意のページで右クリックし、コンテキストメニューから「翻訳履歴を表示」を選択します
3. 履歴ページでは、過去の翻訳を検索したり、言語・サービス・モデルでフィルタリングできます

### 設定の変更

1. 拡張機能アイコンをクリックし、「API設定」ボタンをクリックします
2. 設定ページで、使用するAIサービス、モデル、APIキー、翻訳先言語などを変更できます
3. カスタムモデルの追加や削除も設定ページから行えます

## 無料で使用する方法

Google Gemini APIは無料枠があり、特にGemini 1.5 Flashモデルを使用すれば、無料で高品質な翻訳を利用できます。

1. [Google AI Studio](https://aistudio.google.com/)でアカウント作成しAPIキーを取得
2. 拡張機能の設定でサービスを「Google Gemini」に設定
3. モデルを「Gemini 1.5 Flash」に設定
4. 取得したAPIキーを入力して保存

## プライバシーと安全性

- この拡張機能は、選択したテキストと翻訳結果をローカルのブラウザストレージに保存します
- APIキーは安全に保存され、選択したAIサービスのAPIリクエストにのみ使用されます
- 翻訳データが第三者に共有されることはありません
